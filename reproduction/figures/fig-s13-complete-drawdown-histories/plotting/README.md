# Supplementary Figure S13: rendering

Run `python plotting/render.py` from this figure folder, or `python reproduction/code/plotting/render_all.py --figure fig-s13` from the repository root. The command reads this folder’s aggregate inputs and writes `analysis/rebuilt`. It leaves the frozen publication files in `figures` unchanged. Shared rendering code is in `reproduction/code/plotting`.

The output recreates the figure from aggregate results; it does not rerun the underlying empirical experiment.
